Definition

template<typename GeometryTraits_1, typename VertexData = void, typename EdgeData = void, bool UseVector = false, typename Allocator = std::allocator<char>>
class CGAL::Arrangement_on_curve_1::Closed_topology_traits< GeometryTraits_1, VertexData, EdgeData, UseVector, Allocator >

The class template Closed_topology_traits is a model of the AocTopologyTraits for 1D arrangements embedded on a closed master curve, that is, a curve that includes its two endpoints, parameterized over a closed interval parameter space.

It maintains the arrangement as an alternating sequence of vertices and edges. The class template supports both list-based and vector-based underlying storage structures, and permits optional user data extension on vertices and edges via property maps.

A closed side means that the curve includes its endpoint on that side. Once inserted, the endpoint is the boundary vertex on that side.

Template Parameters
GeometryTraits_1a model of AocTraits_1 with Left_side_category = Closed_side_tag and Right_side_category = Closed_side_tag.
VertexDataoptional user-defined data attached to each vertex (defaults to void).
EdgeDataoptional user-defined data attached to each edge (defaults to void).
UseVectorwhen set to true, stores vertices and edges in std::vector to enable \(O(\log n)\) binary search point location. Descriptors become std::size_t indices. When false (default), uses std::list where descriptors are stable bidirectional iterators.
Allocatorallocator used for internal node and container allocations (defaults to std::allocator<char>).
