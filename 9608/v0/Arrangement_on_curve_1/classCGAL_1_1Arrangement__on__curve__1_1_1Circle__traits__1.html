Circle_traits_1 is a geometry traits model of the AocIdentifiedBoundaryTraits_1 concept for 1D arrangements of points on the unit circle \(\mathbb{S}^1\).

Points are represented as Kernel::Direction_2 objects. Using Direction_2 rather than a floating-point angle gives exact arithmetic when the kernel is exact (e.g., CGAL::Exact_predicates_exact_constructions_kernel).

Parameter space and boundary categories

The parameter space of \(\mathbb{S}^1\) is \([\theta_{\mathrm{ref}}, \theta_{\mathrm{ref}} + 2\pi)\) with the two endpoints identified, where \(\theta_{\mathrm{ref}}\) is the angle of the reference direction \(d_{\mathrm{ref}}\) described below. By default, \(\theta_{\mathrm{ref}} = 0\); the reference direction can be overridden through the constructor. Both sides of the parameter space therefore carry Identified_side_tag:

Reference direction and total order

An optional reference direction \(d_{\mathrm{ref}}\) (default: positive x-axis \((1,0)\)) defines the identification point. The total order on directions is the counter-clockwise (CCW) order starting strictly after \(d_{\mathrm{ref}}\): \(d_{\mathrm{ref}} < d_1 < d_2 < \ldots < d_n < d_{\mathrm{ref}}\) (one full turn).

A direction equal to \(d_{\mathrm{ref}}\) is the identification point: AocIdentifiedBoundaryTraits_1::Is_on_x_identification_1 returns true for it, and AocTraits_1::Compare_x_1 must not be called with it as either argument.

Exact angular comparison

The comparison is implemented using only the kernel predicate Kernel::CompareAngleWithXAxis_2 (no trigonometric computation), which compares the angles in \([0, 2\pi)\) between the positive \(x\)-axis and two directions. If \(d_{\mathrm{ref}}\) is the positive \(x\)-axis, the order of two directions \(d_1\) and \(d_2\) is the order of their angles. Otherwise, the directions whose angles are larger than the angle of \(d_{\mathrm{ref}}\) precede the others, and within each of these two groups, the order is the order of the angles.
