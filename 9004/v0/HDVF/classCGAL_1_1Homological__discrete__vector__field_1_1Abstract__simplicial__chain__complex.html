class CGAL::Homological_discrete_vector_field::Abstract_simplicial_chain_complex< CoefficientRing, SparseMatrixStruct >

The class Abstract_simplicial_chain_complex represents (topological) chain complexes associated to abstract simplicial complexes.

An abstract simplicial complex is a set of simplices, also called cells (class Simplex) such that all the faces of a given simplex also belong to the complex and any two simplices intersect exactly along a common face.

See user documentation of simplicial chain complexes for more details.

Let us point out that cells are indexed along each dimension, thus each simplex is uniquely determined by its dimension and its index in this dimension.

int q ) const

Returns the 0-simplices of a given simplex (that is, the indices of its 0-simplices).

Returns the indices of the 0-simplices included in the simplex of index id_cell and dimension q.

Warning
This does not come to return vertex indices, as dimension 0 simplices enumerate vertices in any order. For instance, if an abstract simplicial complex is built from 3 vertices {1,2,3} such that the enumeration of dimension 0 simplices is: id0: 3, id1 : 2, id2: 1 then the bottom_faces of the 1-simplex {1,2} are two 0-simplices with id 2 and 1.
Parameters
id_cellIndex of the simplex.
qDimension of the simplex.
Returns
A vector of 0-simplex indices.
