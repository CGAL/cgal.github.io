CGAL::OSM::Bitboard Class Reference
Homological Discrete Vector Fields Reference » Sparse Matrices and Vectors Classes

#include <CGAL/OSM/Bitboard.h>

Definition

The class Bitboard implements an accelerating iteration structure, derived from the chess community.

This structure stores a sequence of bits and provides fast forward and reverse iterators over 1 bits (unlike vectors or arrays).

It is used in OSM::Sparse_matrix to build a fast iterator over non-zero chains.
