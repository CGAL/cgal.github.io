template<typename ArrangementA, typename ArrangementB, typename ArrangementR>
class CGAL::Arrangement_on_curve_1::Copy_overlay_visitor< ArrangementA, ArrangementB, ArrangementR >

The class template Copy_overlay_visitor is an overlay visitor that copies the user data of the input cells to the cells of the resulting arrangement.

The data of a resulting cell is copied from the input cell it originates from as follows:

Callback The resulting cell is induced by The data is copied from
create_vertex_vv() a vertex of each input arrangement the vertex of the first
create_vertex_ve() a vertex of the first and an edge of the second the vertex
create_vertex_ev() an edge of the first and a vertex of the second the vertex
create_edge_ee() an edge of each input arrangement the edge of the first

Data is copied only if the corresponding data type of the resulting arrangement is not void and the data type of the source cell is convertible to it; otherwise, the callback function does nothing.

Template Parameters
ArrangementAthe type of the first input arrangement, an instance of Arrangement_on_curve_1.
ArrangementBthe type of the second input arrangement, an instance of Arrangement_on_curve_1.
ArrangementRthe type of the resulting arrangement, an instance of Arrangement_on_curve_1.
