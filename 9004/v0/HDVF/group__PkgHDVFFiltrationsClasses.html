template<typename ChainComplex, typename P>
std::function< double(size_t)> CGAL::Homological_discrete_vector_field::degree_function ( const ChainComplex & complex,
const std::function< double(const P &)> & f )

#include <CGAL/HDVF/Filtration_lower_star.h>

Degree function providing a filtration value for all vertices of the complex.

Given a function mapping a point's coordinates to a degree, degree_function returns a function mapping the index of a vertex to the degree associated to its coordinates.

Parameters
complexThe underlying complex of the filtration.
fA function mapping a point to a degree value. Standard argument functions are Kernel::Compute_x_3(), Kernel::Compute_y_3(), Kernel::Compute_z_3().
