class CGAL::Arrangement_on_curve_1::Arrangement_on_curve_1< GeometryTraits_1, TopologyTraits, BinarySearch >

Arrangement_on_curve_1 represents a subdivision of a continuous 1D curve, referred to as the master curve, into maximally connected subcurves.

The subdivision is represented as a linked list of alternating vertices and edges, referred to as cells, where a vertex maps to a point and an edge maps to an open subcurve. Thus, the operations that obtain incident cells provided by the class template take constant time, and the space needed to store the arrangement is linear in the complexity of the arrangement.

Geometry and Topology Traits

The class is parameterized by a geometry traits (GeometryTraits_1) and a topology traits (TopologyTraits). The geometry traits governs the geometric predicates and boundary-category tags; the topology traits governs the underlying combinatorial data structure (storage, descriptors, and sentinel/boundary book-keeping).

Parameter Space and Boundary Categories

The master curve \(C = \phi_C(X)\) is given by a continuous function \(\phi_C: X \rightarrow \mathbb{R}^d\); it is defined over a one-dimensional interval \(X\) called the parameter space. The parameter space can be open, closed, left-closed, right-closed, or identified. GeometryTraits_1 declares the types Left_side_category and Right_side_category, each of which is one of Open_side_tag, Closed_side_tag, or Identified_side_tag. The static data member, for example, is_identified is true if and only if both categories are Identified_side_tag; that is, the curve is cyclic, such as \(\mathbb{S}^1\). When TopologyTraits is omitted, it defaults to Default_topology_traits<GeometryTraits_1>::type, the topology traits that matches the two categories, e.g., Identified_topology_traits<Circle_traits_1<Kernel>> for Circle_traits_1<Kernel>. Supply the topology traits explicitly to attach user data to vertices or edges, or to use vector storage, e.g.:

using Gt = Circle_traits_1<Kernel>;
using Arr = Arrangement_on_curve_1<Gt, Identified_topology_traits<Gt, Vertex_data, void, true>>;

Traits Object Storing

An arrangement object maintains a smart pointer to a shared immutable geometry traits object, optimizing lifecycle tracking and enabling efficient data synchronization across topological overlays.

Binary-search mode

When BinarySearch = true and TopologyTraits::UseVector = true, the locate() function uses binary search over the sorted vertex vector, reducing point location from \(O(n)\) to \(O(log n)\). Binary-search mode is not supported for an identified parameter space.
