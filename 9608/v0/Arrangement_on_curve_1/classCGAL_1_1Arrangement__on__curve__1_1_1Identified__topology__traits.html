template<typename GeometryTraits_1, typename VertexData = void, typename EdgeData = void, bool UseVector = false, typename Allocator = std::allocator<char>>
class CGAL::Arrangement_on_curve_1::Identified_topology_traits< GeometryTraits_1, VertexData, EdgeData, UseVector, Allocator >

Identified_topology_traits is a topology traits model of AocTopologyTraits for 1D arrangements on a cyclic curve (identified boundary).

When both sides of the parameter space are identified (tag: Identified_side_tag), the curve is cyclic, for example a circle, a direction-space \(\mathbb{S}^1\), or any periodic 1D domain.

Key topological differences from Open_topology_traits:

  • An empty arrangement consists of a single edge that spans the entire curve and no vertices, as in all topology traits; however, every edge of a non-empty arrangement has a vertex on both sides.
  • Vertices and edges form a cyclic sequence: \(\ldots \leftarrow e_0 \rightarrow v_0 \leftarrow e_1 \rightarrow v_1 \ldots\) where the last edge wraps back to the first vertex.
  • A edge incident on the left to a vertex that maps to the identification point provides the canonical entry point for cyclic traversal (locate, overlay).
  • insert_empty(p) creates the very first vertex and a single loop edge (left and right both pointing to that vertex).
