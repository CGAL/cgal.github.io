template<typename C3t3>
class CGAL::Mesh_smoothing_3::C3t3_mesh_projector< C3t3 >

provides projection functions to a mesh defined in a Mesh_complex_3_in_triangulation_3

The class Mesh_smoother creates an AABB_tree for each patch and curve on the mesh. It then defines queries re-projecting entities on the mesh depending on their patch/curve index.
