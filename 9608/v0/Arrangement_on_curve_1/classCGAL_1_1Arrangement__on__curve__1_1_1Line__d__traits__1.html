Definition

template<typename Kernel>
class CGAL::Arrangement_on_curve_1::Line_d_traits_1< Kernel >

Line_d_traits_1 is a geometric traits model of AocTraits_1 designed for subdivisions along an infinite supporting line embedded in a d-dimensional coordinate space.

Points are represented using multi-dimensional dynamic coordinates (Kernel::Point_d). The linear ordering is resolved by computing inner dot products across coordinate dimensions via Cartesian iterator ranges.
