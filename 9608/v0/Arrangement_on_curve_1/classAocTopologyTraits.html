AocTopologyTraits Concept Reference
Reference Manual » Concepts » Topology Object Concepts

Definition

The concept AocTopologyTraits encapsulates the topological data structures, storage layout, memory allocation, and navigation primitives required by CGAL::Arrangement_on_curve_1 to maintain subdivisions of a 1D carrier curve.

◆ create_vertex() [1/2]

Vertex_descriptor AocTopologyTraits::create_vertex ( const Point_1 & p)

creates a new vertex associated with point p without registering it as a boundary vertex or as the identification vertex.

It is used when the caller knows the location of p in the parameter space, which spares the geometric test; the caller registers the vertex if needed.

◆ create_vertex() [2/2]

Vertex_descriptor AocTopologyTraits::create_vertex ( const Point_1 & p,
const GeometryTraits_1 & gt )

creates a new vertex associated with point p.

If p lies on a closed boundary or is the identification point, the vertex is registered as the corresponding boundary vertex or as the identification vertex, respectively; gt is used to determine this.
